# 📌 Evaluación Final Transversal – Semana 9  
### Consulta de Bases de Datos | Duoc UC  

Este repositorio contiene el desarrollo completo de la **Evaluación Final Transversal – Semana 9**, correspondiente a la asignatura **Consulta de Bases de Datos**.  

El proyecto aborda la construcción, organización, seguridad y optimización de una base de datos Oracle, cumpliendo los requerimientos técnicos y de negocio establecidos en el enunciado académico.  

---

## 📂 Contenido del repositorio  

### 📌 `PRY2205_EFT_S9_SOLUCION.sql`  
Archivo principal con todo el desarrollo dividido por usuario Oracle:  
- **CASO 1** → Estrategia de seguridad  
- **CASO 2** → Generación de informe de remuneraciones  
- **CASO 3.1** → Vista optimizada  
- **CASO 3.2** → Creación de índices  

Este script contiene:  
- ✔ Creación de usuarios, roles y privilegios  
- ✔ Creación y asignación de sinónimos públicos y privados  
- ✔ Construcción de tabla `CARTOLA_PROFESIONALES`  
- ✔ Sentencia `INSERT ... SELECT ...` para poblar su contenido  
- ✔ Creación de vista `VW_EMPRESAS_ASESORADAS`  
- ✔ Optimización mediante índices  

---

## 🧱 Requisitos previos  

Instalar y ejecutar Oracle SQL Developer o ambiente equivalente, luego:  

1. Crear los usuarios y roles definidos.  
2. Ejecutar el script oficial de creación y población del modelo entregado por el docente.  
3. Ejecutar este archivo principal.
