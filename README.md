# PRY2205 — Semana 3 (Forma C)

Este repositorio contiene el script `consultas_semana3.sql` con las 3 consultas solicitadas:
1) Clientes por rango de renta
2) Sueldo promedio por categoría y sucursal
3) Arriendo promedio por tipo de propiedad

## Instrucciones rápidas
1. Ejecuta los scripts de la cátedra para crear el **usuario** y **esquema poblado**.
2. Abre `consultas_semana3.sql` en SQL Developer.
3. Al ejecutar, el editor te pedirá:
   - `RENTA_MINIMA` y `RENTA_MAXIMA` (caso 1)
   - `SUELDO_PROMEDIO_MINIMO` (caso 2)

El script no usa `WITH` y respeta alias, formatos y ordenamientos.
